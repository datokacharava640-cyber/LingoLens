# 🚀 LingoLens Ultra Pro

LingoLens არის თანამედროვე მრავალენოვანი სმარტ-თარჯიმანი, რომელიც იყენებს AI ტექნოლოგიებს ტექსტის, ფოტოს (OCR) და ხმის (TTS) დასამუშავებლად.

## ✨ ძირითადი ფუნქციები
- 🌍 **მრავალენოვანი თარგმნა:** 20+ მსოფლიო ენისა და ქართული ენის მხარდაჭერა.
- 📷 **OCR / AR კამერით თარგმნა:** ფოტოდან ტექსტის ავტომატური ამოცნობა და თარგმნა.
- 🗣️ **Edge-TTS ხმოვანი ასისტენტი:** ტექსტის ბუნებრივი გაჟღერება High-Quality ხმებით.
- 📊 **გრამატიკული ანალიზი:** ტექსტის დეტალური სტატისტიკა და სტრუქტურული ანალიზი.
- ⚡ **FastAPI & Vercel backend:** სწრაფი ასინქრონული სერვერლეს API.

## 🛠️ ტექნოლოგიები (Tech Stack)
- **Frontend / Mobile App:** Python, Kivy, Plyer
- **Backend API:** FastAPI, Edge-TTS, Deep-Translator, PyTesseract, Uvicorn
- **Deployment:** Vercel / Cloud Engine
